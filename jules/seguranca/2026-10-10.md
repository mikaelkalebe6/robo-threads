# Relatório de Auditoria de Segurança

Este relatório apresenta a auditoria semanal de segurança realizada no repositório. O foco desta verificação é avaliar as alterações e novos códigos adicionados desde o relatório anterior de 2026-10-09.

Conforme premissas estabelecidas, considera-se já decidido que o repositório permanece privado, os valores de segredos são mascarados no ambiente de execução e as permissões de acesso são definidas no nível de cada job.

## Comparativo com o Relatório Anterior e Mudanças Recentes

Desde o relatório de 2026-10-09, foram adicionados a integração de geração de artes via inteligência artificial com o Google Stitch, o script de renderização de carrosséis e o fluxo de automação correspondente.

## Achados da Auditoria

### 1. Envio de chave de API em requisições de download para links externos
* **Arquivo e linha:** `stitch.py` (linhas 135 e 145)
* **Gravidade:** Média
* **Por que importa:** A função de download inclui o cabeçalho de autenticação com a chave de API em qualquer requisição efetuada. Ao baixar imagens secundárias ou recursos cujo link aponte para servidores de terceiros fora da plataforma oficial, a chave da API pode ser enviada no cabeçalho HTTP para esses servidores externos.
* **Correção sugerida:** Remover o cabeçalho de autenticação das requisições de download de imagens ou restringir o envio da chave de API exclusivamente para as chamadas direcionadas aos endereços oficiais do serviço.

### 2. Versionamento de respostas brutas e mensagens de erro em arquivo de log
* **Arquivo e linha:** `stitch.py` (linhas 86 a 90 e 290 a 295)
* **Gravidade:** Baixa
* **Por que importa:** O histórico de execuções do gerador de imagens salva detalhes do retorno da API no arquivo `carrosseis/stitch_log.json`, o qual é mantido e salvo no repositório. Embora exista checagem prévia no fluxo para evitar o commit da chave de API, gravar respostas brutas no histórico do Git pode expor informações operacionais temporárias e aumentar desnecessariamente o volume do repositório.
* **Correção sugerida:** Tratar e simplificar as mensagens de retorno antes de salvar no log ou adicionar o arquivo `carrosseis/stitch_log.json` ao arquivo de ignorados do Git (`.gitignore`).

### 3. Disparo automático de fluxo de automação em edições na fila
* **Arquivo e linha:** `.github/workflows/artes-ia.yml` (linhas 3 a 10)
* **Gravidade:** Baixa
* **Por que importa:** A inclusão ou alteração de arquivos na pasta de fila de carrosséis dispara automaticamente a execução do fluxo de geração de artes. Caso ocorram envios frequentes de edições em sequência, execuções simultâneas podem concorrer ao tentar salvar atualizações de volta na ramificação principal.
* **Correção sugerida:** Incluir regra de concorrência para cancelar execuções anteriores em andamento ou manter o acionamento do fluxo configurado prioritariamente por execução manual.
