# Relatório de Auditoria de Segurança

Este relatório apresenta a auditoria semanal de segurança realizada no repositório. O objetivo é avaliar as atualizações nos fluxos de automação do GitHub Actions, nos scripts em Python e nos arquivos de dados versionados, comparando o cenário atual com o relatório do dia 2026-10-17.

Conforme as premissas estabelecidas, considera-se já decidido que o repositório permanece privado, os valores de segredos são mascarados no GitHub Actions e as permissões de acesso são configuradas por job.

## Comparativo com o Relatório Anterior e Evolução do Código

Na última semana, a principal alteração no código fonte ocorreu no arquivo `bot.py`. Foi implementada a liberação imediata do link de afiliado em postagens do tipo achadinho assim que algum usuário solicita o link nos comentários. Anteriormente, o robô aguardava atingir a meta de visualizações ou o limite de tempo estipulado para publicar o link.

Quanto aos pontos auditados no relatório anterior do dia 2026-10-17:

A ausência da marcação de publicidade em respostas diretas a comentários solicitando links permanece ativa por decisão do proprietário do projeto. A funcionalidade nova de liberação antecipada de achadinhos segue essa mesma regra, anexando o link na resposta sem a marcação de publicidade.

O salvamento do log de execução em `carrosseis/stitch_log.json` continua ocorrendo durante o processo de geração de imagens. O fluxo de automação mantém a verificação prévia para impedir a inclusão acidental de chaves de API no repositório.

## Achados da Auditoria

### 1. Ausência da marcação de publicidade em respostas enviadas a quem solicita o link
* **Arquivo e linha:** `bot.py` (linha 2514)
* **Gravidade:** Média
* **Por que importa:** Quando o robô detecta a intenção de pedido de link ou interesse em comprar um produto, a nova função libera o link do achadinho e responde ao usuário sem incluir a hashtag de publicidade. As diretrizes das plataformas exigem a identificação clara de links de afiliados. O envio recorrente de links de afiliados sem essa identificação pode gerar restrições de alcance ou bloqueios pela plataforma.
* **Correção sugerida:** Incluir a sinalização de publicidade com hashtag ao enviar links comerciais nas respostas.

### 2. Versionamento contínuo de arquivo de log de geração de artes no Git
* **Arquivo e linha:** `.github/workflows/artes-ia.yml` (linha 39) e `stitch.py` (linhas 296 e 343)
* **Gravidade:** Baixa
* **Por que importa:** O arquivo `carrosseis/stitch_log.json` é atualizado e salvo no histórico do Git a cada execução do gerador de imagens. Embora exista verificação para barrar a gravação de segredos, salvar logs operacionais continuamente aumenta o tamanho do histórico do repositório com dados temporários.
* **Correção sugerida:** Adicionar o arquivo `carrosseis/stitch_log.json` no arquivo `.gitignore` para não incluir logs operacionais no repositório.
